Critical Performance Issues Identified
1. Largest Contentful Paint (LCP) - 4.2s (Poor)
Impact: Largest element takes too long to render, hurting perceived load time.

Recommendations:

Preload critical fonts: Already implemented preload hints, but optimize by converting TTF fonts to WOFF2 format (30-50% smaller)
Optimize font loading: Implement font subsetting to only include Latin characters used in dashboard
Image optimization: Compress logo images (FSD Africa, BFA Global, Catalyst Fund) - likely using PNG when WebP would be 25-35% smaller
Code splitting: Implement route-based code splitting for dashboard vs bilateral agreements pages
Lazy load below-fold components: Defer loading of BilateralAgreements, DataTable, and heavy visualizations until they're about to enter viewport
2. Total Blocking Time (TBT) - 520ms (Needs Improvement)
Impact: Main thread is blocked, preventing user interactions.

Recommendations:

Bundle size reduction:
Remove unused dependencies (e.g., openai in client bundle if only used server-side)
Tree-shake lodash if imported (use individual imports)
Consider replacing Recharts with a lighter charting library for simple charts
Web Workers: Move heavy computations (e.g., filtering 72M+ credits data) to background threads
Debounce filters: Add 300ms debounce to filter changes to prevent excessive re-renders
Virtual scrolling: Implement for DataTable component (currently rendering all rows)
3. First Contentful Paint (FCP) - 2.1s (Needs Improvement)
Impact: User sees blank screen for too long.

Recommendations:

Critical CSS extraction: Inline critical Tailwind CSS for above-the-fold content
Eliminate render-blocking resources:
Move lord-icon script to async instead of defer
Remove unused Google Analytics script during initial load (lazy load after FCP)
Reduce initial bundle size: Current JavaScript bundle likely >500KB
Server-side rendering (SSR): Consider implementing for initial dashboard metrics
4. Cumulative Layout Shift (CLS) - 0.08 (Needs Improvement)
Impact: Content jumping around during load.

Recommendations:

Reserve space for skeleton loaders: Add explicit heights to loading states in MetricsCards, TopBuyers, KeyInsights
Font fallback metrics: Use size-adjust, ascent-override, descent-override CSS properties to match fallback fonts to Stack Sans dimensions
Image dimensions: Ensure all <img> tags have explicit width/height attributes
Lord-icon placeholders: Reserve exact space for animated icons before they load
5. Speed Index - 3.8s (Poor)
Impact: Visual completeness takes too long.

Recommendations:

Progressive enhancement: Show static content first, enhance with interactivity later
Skeleton screens optimization: Current skeletons should appear instantly (within 100ms)
Reduce animation complexity: Framer Motion animations may be delaying perceived speed
Prioritize visible content: Load header, metrics cards, and key insights before charts
